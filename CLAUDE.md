The single source of truth for design is the claude.ai doc 「《出走》策划文档 v2」 (https://claude.ai/artifact/SfvL3oka1WFRH3VxCoXiQB). Add every new decision there. The older doc 「新手村剧情文案策划」 is archived; never edit it or take decisions from it.

## Decisions already made
- Format (decided 2026-10-21): a narrative CARD game. Days, actions, people, jobs and items are cards. Each location is one large hand-painted illustration generated by Gemini (no people in it), animated in code (water, clouds, rice waves, light). Characters are Gemini portraits driven by the code rig in `game/live-portrait-demo/` (breathing, blinking, head turn, hair sway, lip flap). Dialogue uses synthesized babble voice; real voice lines, SFX and music are decided last.
- The 3D walk prototype in `game/xiangye-3d/` is paused and kept only as reference. Do not extend it unless asked.
- Real-world photos are not used: no licensing risk, one consistent art style. Never pull images from the web into the game.
- 乡野村 locations (9): 村口, 田埂, 石桥小溪, 大河, 村小学, 老街小卖部, 山林竹林, 村尾老庙, 山顶. Spring daytime first, then dusk/night and other seasons.
- Ship to Steam via Electron (`build.py --offline` style single page). Steam is the main platform; China release needs a 版号, so not now.
- Look: Japanese hand-painted (Ghibli-like) palette. Art comes from Gemini.
- UI: option C "乡间木牌" — hanging wooden sign, cream boards with thick brown rims (#5e4027), wooden buttons, rounded dialogue box with a wooden name tag and round portrait. Do not switch back to the earlier thin black-bordered paper notes.
- Chapter 1 is a mountain village named 乡野村 (田园、小溪、学校、山、草木) with four seasons; staying longer moves the seasons on. Player can stay several days; jobs refresh daily. Hero name is chosen at the start (default 陈默). Game title: 《出走》.
- Not decided yet: the villagers (who lives in 乡野村), their jobs/stories, the card rules, whether the prologue keeps the "repeat the same day" loop.

## How the card page is built (main line)
- Edit `game/xiangye-cards/index.src.html`, then `python3 game/xiangye-cards/tools/build.py` → `index.html` (all images inlined; the 小路 portrait shader is copied from `game/live-portrait-demo/index.src.html`).
- `tools/make_masks.py` makes per-scene masks (R water, G plants, B sky) + thumbs into `assets/processed/scenes/`; water polygons and sky limits are hand-tuned per scene there.
- `SC` lists the 9 locations (particle kind, light rays, cloud shadow, fog band, special sway rects in 1024x572 image coords). Time of day `ST.tod` 0–3 (上午/中午/傍晚/夜晚) is graded in the scene shader.

## How the 3D page is built (paused)
- Edit `game/xiangye-3d/index.src.html`; never edit `dist/`. `/*ASSETS*/` is replaced by `assets.json` at build time.
- Terrain height `H(x,z)`, collision `blocked(x,z)`, paths `ALLPATHS`, fields `FIELDS`, houses `HOUSES`.
- Stylized parts: `TM()` toon material, `ink()` edge lines, `hull()` character outlines, `HERO` procedural walk, `Foliage()` leaf-card trees, `GRASS` (player-following patch over a baked heightmap `HM`), `RICE` (seasonal rows in fields).
- Season/time tables: `SEASONS`, `TIMES`; `applySeason()` / `applyLight()` push colours into every shader.

## Testing
Headless Chromium with SwiftShader runs at 1–2 fps, so judge visuals from screenshots, not smoothness, and wait several seconds after teleporting the player (the camera lerps). Route the jsdelivr three.js URL to `vendor/three.min.js` when testing offline.
